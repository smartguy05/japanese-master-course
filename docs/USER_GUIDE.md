## Getting Started

- **Progress Tracking** - Monitor your improvement over time

- Beginners starting from zero Japanese knowledge
- Intermediate learners preparing for JLPT N5-N3

Our platform uses multiple proven methodologies:
1. **Spaced Repetition (SRS)** - Review at optimal intervals

4. **Immediate Feedback** - AI provides instant corrections
5. **Gamification** - Streaks and achievements keep you motivated

## Flashcard System

### How Spaced Repetition Works

Our SRS algorithm (SM-2) schedules reviews based on how well you remember:

```
Perfect Recall (5)    → Next review in 2 weeks
Good Recall (4)       → Next review in 1 week
Correct with Effort (3) → Next review in 3 days
Incorrect (1-2)       → Review again today
Complete Forget (0)   → Restart learning
```

### Review Process

1. **View Front** - Japanese character or word
2. **Recall Answer** - Try to remember meaning
3. **Reveal Back** - Check the answer
4. **Rate Yourself** - How well did you remember?
   - 0 = No idea
   - 1 = Wrong but familiar
   - 2 = Wrong but close
   - 3 = Correct but hard
   - 4 = Correct, slight hesitation
   - 5 = Perfect, instant recall
5. **Next Card** - Algorithm schedules next review

### Card Types

**Vocabulary Cards**
- Front: Japanese word (水)
- Back: Reading (みず) and meaning (water)

**Kanji Cards**
- Front: Kanji character (水)
- Back: Readings (すい, みず), meaning, stroke order

**Grammar Cards**
- Front: Grammar pattern (〜ます)
- Back: Usage, examples, meaning

### Review Session Best Practices

- **Consistency** - Review every day at same time
- **Honest Ratings** - Rate accurately, not optimistically
- **Focus** - No distractions during reviews
- **Time Limit** - 20-30 minute sessions are optimal
- **Think First** - Try to recall before revealing answer

### Custom Flashcards

## AI Conversation Practice

### How It Works

Chat with Claude AI, an advanced language model that:

### Starting a Conversation

1. Navigate to "Conversation Practice"

**Business** (N3 level)

- Email writing

- Meeting etiquette

### Grammar Corrections

AI provides corrections like:

**Your Message:**
```
私は学校に行きました
```

**AI Response:**
```
良いですね！However, when talking about going to a destination,
it's more natural to use へ instead of に:
「私は学校へ行きました」

に is used more for the purpose of an action, while へ
emphasizes the direction or destination.
```

### Conversation Tips

- **Start Simple** - Use what you know
- **Make Mistakes** - That's how you learn!
- **Read Corrections** - Actually understand them
- **Practice Patterns** - Reuse corrected forms
- **Type in Japanese** - Use IME keyboard (not romaji)

### Japanese Input Methods

**Windows:**
1. Install Japanese language pack
2. Press `Windows + Space` to switch
3. Type romaji, it converts to hiragana
4. Press `Space` to convert to kanji
5. Press `Enter` to confirm

**Mac:**
1. System Preferences → Keyboard → Input Sources
2. Add Japanese - Hiragana
3. Press `Command + Space` to switch
4. Type and press `Space` to convert

**Mobile:**
1. Install Japanese keyboard in settings
2. Switch keyboard when typing
3. Use predictive text

## Frequently Asked Questions

**Q: How long until I'm fluent?**

A: Fluency takes years. Our platform aims for N3 (intermediate) in 12-18 months with daily study. JLPT N2 (business level) takes 2-3 years.

**Q: Should I learn hiragana first?**

A: Yes! Master hiragana and katakana before diving into kanji and complex grammar.

**Q: How many flashcards per day?**

A: Start with 10-20 new cards/day. Adjust based on review load. Quality over quantity.

**Q: Can I use this for JLPT preparation?**

A: Yes! The curriculum aligns with JLPT levels N5-N3. Practice tests coming in v0.3.0.

**Q: Is the AI conversation enough?**

A: AI practice is great for grammar and vocabulary, but also seek real human conversation for natural flow and cultural context.

**Q: Can I reset my progress?**

A: Contact support to reset. Better to archive old cards and start fresh sections.

**Q: How do I type Japanese on my device?**

A: See [Japanese Input Methods](#japanese-input-methods) section above.

**Q: Why did I lose my streak?**

A: Streaks require studying every calendar day. Review at least one card daily to maintain streaks.

**Q: Can I study offline?**

A: PWA offline mode planned for v0.3.0. Currently requires internet connection.

**Q: Is my data secure?**

A: Yes. Passwords are hashed, data is encrypted, and we never share your information.
